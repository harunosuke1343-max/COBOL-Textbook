HTML ファイルでのフローチャート作成方法 比較

同じ「入力 → 検証 → 処理／エラー → 終了」の流れを5つの方法で描画します。

1. Mermaid.js — テキスト記法で自動描画

手軽 CDN対応 保守性◎

Markdown風の記法だけで図が描けます。GitHub でもサポートされています。

<pre class="mermaid"> flowchart TD A([開始]) --> B[データを入力する] B --> C{有効か？} C --"Yes"--> D[処理を実行] C --"No"--> E[エラーを表示] D --> F([終了]) E --> F </pre>
flowchart TD
  A([開始]) --> B[データを入力する]
  B --> C{有効か？}
  C --"Yes"--> D[処理を実行]
  C --"No"--> E[エラーを表示]
  D --> F([終了])
  E --> F

2. SVG — 手書きベクター描画

軽量 リサイズ対応 自由度◎

SVG 要素を直接書く方法。レスポンシブで、スタイルも CSS で制御できます。

<svg viewBox="0 0 500 340"> <!-- 矩形・菱形・線を直接記述 --> <rect x="175" y="10" width="150" height="40" rx="20" .../> <line x1="250" y1="50" x2="250" y2="80" .../> ... </svg>

3. vis.js Network — インタラクティブグラフ

ドラッグ可能 ズーム対応 ダイナミック

ノードをドラッグしたりズームできるインタラクティブなフローチャート。

const network = new vis.Network(container, data, options); data.nodes = [ {id:1, label:'開始', shape:'ellipse'}, {id:2, label:'データを入力', shape:'box'}, ... ];

4. CSS Grid — HTML + CSS だけで描画

JavaScript不要 SEO対応 セマンティック

CSS Grid と擬似要素で矢印を描画。外部ライブラリ unnecessary な場合に便利。

.flow-step { grid-column: 3; grid-row: 1; } .flow-decision { grid-column: 3; grid-row: 2; } .flow-left { grid-column: 1; grid-row: 2; } .flow-right { grid-column: 5; grid-row: 2; }

5. HTML テーブル — 表組みで表現

最もシンプル ゼロ依存 古めの環境◎

<table>とHTML文字実体参照だけで構成。JavaScriptもCSSの高度な機能も不要。

<table> <tr><td class="node">開始</td></tr> <tr><td>▼</td></tr> <tr><td class="node">データを入力</td></tr> ... </table>

まとめ — 各手法の特徴

方法 JavaScript 外部ライブラリ インタラクティブ 保守性 推奨ケース
Mermaid.js 必要 Mermaid ✗ ◎ 最もおすすめです。テキストで図を記述・バージョン管理できます
SVG 不要 なし ✗ △ JSなしで綺麗な図が必要。編集にはIllustrator等が便利
vis.js 必要 vis-network ◎ ◎ ドラッグ・ズーム・ダイナミック更新が必要な場合
CSS Grid 不要 なし ✗ ◎ ゼロ依存でSEO対応の構造付き図が必要
HTMLテーブル 不要 なし ✗ △ 外部ツールなしで即座に簡易図が必要な場合
